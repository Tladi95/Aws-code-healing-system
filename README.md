# Ledgerly Expense Tracker

A React dashboard with Flask and SQLAlchemy CRUD APIs for managing personal expenses.

## Run the frontend

```bash
npm install
npm run dev
```

## Run the backend

From `backend/`:

```bash
pip install -r requirements.txt
set DATABASE_URL=postgresql+psycopg2://postgres:password@localhost:5432/expense_tracker
python app.py
```

Create `backend/.env` from `backend/.env.example` and set your PostgreSQL password. The backend requires PostgreSQL and will not fall back to SQLite.

Available API routes:

- `GET /api/expenses`
- `POST /api/expenses`
- `PATCH /api/expenses/<id>`
- `DELETE /api/expenses/<id>`

## Run with Docker

```bash
docker compose up --build
```

Open `http://localhost:8080`. Docker runs the React frontend, Flask API, and PostgreSQL database together. The database data is stored in the `postgres_data` volume.
